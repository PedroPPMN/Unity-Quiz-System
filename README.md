# Unity Quiz System

Reusable quiz flow for Unity 6 with:

- True/False, Fill-in-the-blank, Drag-and-drop question types
- Pluggable `IQuizValidator`
- Pagination controller
- JSON-driven quiz definitions in `StreamingAssets`

## Run

1. Open in Unity Hub.
2. Create a Canvas with Text + InputField + Buttons.
3. Attach `QuizDemoView` and wire references.
4. Press Play.
